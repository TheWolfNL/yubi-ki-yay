No more staring at a blinking LED

When git signs a commit or ssh reaches for your key, Yubi Ki-Yay shows a banner on the screen you're working on, prints a line in your terminal, plays a sound and flashes the menu bar, all saying what triggered it.

A banner where you're looking

It slides onto your active screen without stealing focus, then disappears after 10 seconds. Click or press Esc to dismiss it sooner.

A line in your terminal

A bold yellow prompt with a bell, right above the command that's waiting. It also catches the eye of AI agents running in your shell.

Sound and menu bar

Pick a system sound or add your own. The menu bar icon can stay visible, appear only when a touch is needed, or stay hidden.

Install

For macOS 12 or later, and a YubiKey whose OpenPGP keys require a touch, used through gpg-agent for ssh and git signing.

  1. Install the app

    brew install --cask thewolfnl/tap/yubi-ki-yay

    This installs Yubi Ki-Yay.app and the yubikiyay command. Open the app once and turn on Start at login in its settings.

  2. Alert before ssh uses your key

    Save this script and make it executable with chmod +x ~/.local/bin/yk-touch-notify. It exits with 1 on purpose, so the Match block never changes your ssh settings.

    ~/.local/bin/yk-touch-notify
    #!/usr/bin/env bash
yubikiyay notify "ssh ${1:-?}"
exit 1

    Then add a line to your ssh config for each host whose key is on the YubiKey:

    ~/.ssh/config
    Match originalhost github.com exec "~/.local/bin/yk-touch-notify %n"

  3. Alert before git signs

    A small wrapper around gpg that alerts when signing, and stays quiet when only verifying:

    ~/.local/bin/yk-gpg
    #!/usr/bin/env bash
case " $* " in
  *" --verify "*) ;;
  *) yubikiyay notify "git signing" ;;
esac
exec gpg "$@"
    chmod +x ~/.local/bin/yk-gpg
git config --global gpg.program ~/.local/bin/yk-gpg

  4. Try it

    yubikiyay notify "test alert"
The app is ad-hoc signed, not notarized. The Homebrew cask clears macOS's quarantine flag so Gatekeeper lets it open. If a hook runs where Homebrew isn't on PATH, use the full path /opt/homebrew/bin/yubikiyay (/usr/local/bin on Intel Macs).
